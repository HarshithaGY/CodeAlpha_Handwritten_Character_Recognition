# ✍️ InkVision AI

An AI-powered handwritten character recognition system built using Python, CNN, TensorFlow and Streamlit.

## Features
- Draw handwritten letters using a mouse.
- Upload character images.
- Recognize English alphabets A–Z.
- Display prediction confidence.
- Show top 5 predictions.
- Interactive AI dashboard.

## Technologies
- Python
- TensorFlow / Keras
- CNN
- EMNIST Letters Dataset
- Streamlit
- NumPy
- Pillow

## Model Performance
- Test Accuracy: 93.04%
- Training Samples: 88,800
- Testing Samples: 14,800
- Classes: 26 (A–Z)

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
